Developer Dashboard & Portfolio

WDD 231 Individual Website Project Site Plan

1. Site Name & Purpose

Site Name: Developer Dashboard & Portfolio

Rationale: The name highlights a dual-purpose web platform: dynamic system monitoring alongside a structured project showcase.

Site Purpose: Provide a dynamic portal fetching live repository metrics, software release notes, and detailed system specs via JavaScript APIs.

2. Target Audience & Scenarios

Target Audience: Software recruiters, engineering managers, and open-source contributors looking for project metrics and technical architecture details.

Scenarios

  • Scenario A: "I need to filter project repositories by C++ or Rust to evaluate systems programming experience."
  • Scenario B: "I want to request detailed architecture specifications or contact the developer directly."

3. Color Scheme

Primary Slate (#0F172A), Secondary Steel (#1E293B), Accent Emerald (#10B981), and Off-White Background (#F8FAFC).
